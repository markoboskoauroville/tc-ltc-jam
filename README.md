# TC LTC JAM

Standalone Android timecode generator for synchronization.

- 25 fps visual time-of-day timecode
- 48 kHz mono SMPTE LTC output
- No Sony USB, Bluetooth, OCR, camera, clap, or synchronization permissions
- App package: `com.mantraproductions.tcltcjam`

Open the app and turn on **AUDIO LTC OUT**. The display and LTC sound use the phone clock.
